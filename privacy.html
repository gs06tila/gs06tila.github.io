Integritetspolicy för BRF-agenten

Senast ändrad 2026-11-22.

Vem använder appen

BRF-agenten används bara av Tim, med Tims eget Google-konto. Appen är inte avsedd för andra och används bara med Tims Google-konto.

Vilken Google-data appen använder

Appen läser filer i en mapp i Tims Google Drive. Den kan också lägga till och flytta filer i den mappen när Tim ber om det. Appen använder ingen annan Google-data.

Var data lagras

Text ur filerna lagras lokalt på Tims egen dator och server. Data delas inte med andra och säljs inte.

Anthropics API

När Tim ställer en fråga skickas utdrag ur dokumenttexten till Anthropics API för att svaret ska kunna skrivas. Det görs bara för att svara på Tims frågor.

Reklam

Ingen data används för reklam.

Återkalla åtkomsten

Åtkomsten tas bort på https://myaccount.google.com/permissions. Välj BRF-agenten och ta bort åtkomsten.

Privacy policy for BRF-agenten

Last updated 2026-11-22.

Who uses the app

BRF-agenten is used only by Tim, with Tim's own Google account. The app is not intended for others and is used only with Tim's Google account.

Google data the app uses

The app reads files in one folder in Tim's Google Drive. It can also add and move files in that folder when Tim asks it to. The app uses no other Google data.

Where data is stored

Text from the files is stored locally on Tim's own computer and server. Data is not shared with anyone and is not sold.

Anthropic's API

When Tim asks a question, excerpts of document text are sent to Anthropic's API so that the answer can be written. This is done only to answer Tim's questions.

Advertising

No data is used for advertising.

Revoking access

Access can be removed at https://myaccount.google.com/permissions. Select BRF-agenten and remove its access.
